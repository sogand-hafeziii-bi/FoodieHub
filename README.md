
# Restaurant Ordering System

## About the Project

This project is a web-based restaurant ordering system developed as part of a university project.

The application allows customers to browse available food items, create accounts, log in, and place food orders. It also provides an administrative dashboard for managing food items, categories, and customer orders.

## Features

### Customer Features
- User registration and login
- Browse available food items
- View food details
- Place food orders
- View order history and order status

### Admin Features
- Admin authentication
- Add new food items
- Manage food categories
- View customer orders
- Update order status
- Delete orders

## Technologies Used

- React.js
- JavaScript
- Node.js
- CSS
- MySQL
  

## Project Structure

The application consists of two main parts:

- Frontend: User interface and customer/admin pages
- Backend: Server-side routes, authentication, and database operations

## Installation and Setup

1. Install Node.js and XAMPP.
2. Import the project database into phpMyAdmin.
3. Open the backend and frontend folders in Visual Studio Code.
4. Install the required dependencies.
5. Start the backend server.
6. Start the frontend application.
